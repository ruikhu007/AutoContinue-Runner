## Reproduction notes / 复现提示

- Run from a clean test profile without personal accounts or unrelated browser tabs.
- Include visible timestamps and actual app version; no synthetic performance counters.
- Keep the full screen recording uncut for an internal audit and make a shorter edit for social sharing if desired.
- Show only scenarios that the currently published build actually handles.
- Do not claim unattended 24/7 action or any bypass of ChatGPT/Claude usage limits.
